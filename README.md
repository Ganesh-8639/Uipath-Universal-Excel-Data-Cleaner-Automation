# Universal Excel Data Cleaner

## Description

A dynamic UiPath automation that cleans different Excel files without relying on fixed column names. It removes unnecessary spaces, missing records, empty columns, and duplicate data, then generates a clean Excel output.

## Features

- Works with different Excel structures
- Cleans column headers and cell values
- Removes unnecessary spaces
- Removes rows with missing data
- Removes empty columns
- Removes duplicate records
- Standardizes common values
- Generates a cleaned Excel file

## Technologies Used

- UiPath Studio
- Excel
- DataTable
